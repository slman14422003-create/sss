# تطبيق رسائل iPhone Style

تطبيق مراسلة بسيط مكتوب بلغة Java للـ Android، تصميمه يحاكي مظهر تطبيق الرسائل على iOS.

## مميزات

- واجهة رسائل على شكل فقاعة أزرق للرسائل المرسلة وفضي للرسائل المستقبلة
- إدخال نص مع زر إرسال على شكل أيقونة iOS
- يستخدم RecyclerView لعرض القائمة
- محاكاة رد تلقائي لتجربة الواجهة
- إعداد GitHub Actions لبناء الـ APK تلقائيًا
